# Community flyers

The community page hangs fifteen session flyers (`f0.jpg` … `f14.jpg`) and
reuses three of them on the format cards.

All fifteen are present, exported from the `flyers/` folder of the Claude
Design project `6a001235-c66a-47ec-867c-58727c83dccb`. They are a mix of
square (420×420) and portrait (420×554 to 420×594), so each is displayed on a
square tile with `object-fit: contain` and both orientations sit correctly
without cropping.
