# Community flyers

The community page hangs fifteen session flyers (`f0.jpg` … `f14.jpg`) and
reuses three of them on the format cards.

They live in the Claude Design project
`6a001235-c66a-47ec-867c-58727c83dccb`, under `flyers/`. Export them from there
and drop them in this directory — the filenames match one-to-one.

Each is displayed on a square tile with `object-fit: contain`, so portrait and
landscape flyers both sit correctly without cropping. The page builds and lays
out with them missing.
