# Design references — industry pages

The six `.dc.html` prototypes for the `/solutions/*` pages, copied out of the
Claude Design project `6a001235-c66a-47ec-867c-58727c83dccb` so they can be read
without a `/design-login`.

They are **design references, not production code**: self-contained HTML using
the prototype's own runtime (`support.js`, which the handoff says not to port).
Read them for structure, colour, copy and behaviour; rebuild in this codebase's
patterns. Safe to delete once the pages are built.
